# Подключение ИИ к «Нашему рациону»

В архив добавлен `ai-integration.js`. Он не содержит ключей: кнопка ИИ отправляет текущий контекст питания в локальный мост `ai-server`, а мост передаёт запрос Hermes.

## Настройка на компьютере

1. В `%LOCALAPPDATA%\hermes\.env` добавьте:

   ```env
   API_SERVER_ENABLED=true
   API_SERVER_KEY=change-me-local-dev
   ```

   Если `API_SERVER_KEY` уже есть, оставьте его и используйте то же значение в мосте.
2. Перезапустите Hermes gateway.
3. Скопируйте `ai-server/.env.example` в `ai-server/.env` и укажите тот же `HERMES_API_KEY`.
4. В PowerShell в папке `ai-server` выполните:

   ```text
   node server.mjs
   ```

5. Откройте `http://127.0.0.1:8787/healthz`. Ответ `{"ok":true}` означает, что мост запущен.
6. Откройте приложение на GitHub Pages, нажмите кнопку лягушки, напишите вопрос и выберите **«Спросить ИИ»**.

Кнопка **«Открыть раздел»** оставляет прежний безопасный сценарий: она только подставляет данные в форму и ничего не сохраняет автоматически.

Ключ OpenAI остаётся внутри Hermes, ключ API Hermes — в локальных файлах компьютера. В GitHub Pages они не попадают.

Текущий мост рассчитан на проверку на этом компьютере. Пока компьютер выключен, ИИ-кнопка страницы работать не будет. Для телефона и второго компьютера следующим шагом понадобится HTTPS-размещение моста.
