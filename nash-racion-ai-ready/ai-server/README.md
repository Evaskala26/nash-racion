# Локальный мост ИИ для «Нашего рациона»

Мост принимает запросы от страницы приложения и передаёт их локальному API Hermes. Ключи OpenAI и Hermes не попадают в GitHub Pages и не записываются в `ai-integration.js`.

## Один раз настроить Hermes

В файл `%LOCALAPPDATA%\hermes\.env` добавь:

```env
API_SERVER_ENABLED=true
API_SERVER_KEY=change-me-local-dev
```

Если в файле уже есть `API_SERVER_KEY`, используй его значение в `.env` моста. После изменения перезапусти Hermes gateway. API Hermes должен слушать `http://127.0.0.1:8642`.

## Запуск моста

1. Скопируй `.env.example` в `.env`.
2. В `.env` укажи тот же `API_SERVER_KEY`, что и в Hermes.
3. Открой PowerShell в папке `ai-server` и выполни `node server.mjs`.
4. Проверь в браузере `http://127.0.0.1:8787/healthz`: должен открыться ответ `{"ok":true}`.

После этого открой приложение на GitHub Pages, нажми кнопку лягушки, напиши вопрос и выбери «Спросить ИИ». Кнопка «Открыть раздел» оставляет прежний ручной сценарий и ничего сама не меняет.

Ограничение текущего варианта: мост работает только пока включён компьютер. Для доступа с телефона или другого компьютера его позже нужно будет разместить на защищённом HTTPS-сервере с отдельным доменом и секретом.
